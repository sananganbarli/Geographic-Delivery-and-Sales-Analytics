# Geographic-Delivery-and-Sales-Analytics
Geospatial &amp; Delivery Analytics Dashboard analyzing regional sales coverage, courier performance, and manager operations across Azerbaijan.

![Map Preview](Screenshot%202026-10-21%20163335.png)


## Project Overview
This project features an interactive **Geospatial & Field Operations Dashboard** designed to visualize sales coverage, delivery density, and courier distribution across regional hubs in Azerbaijan.

The primary goal is to optimize field logistics, monitor personnel performance (managers and couriers), and evaluate regional market potential.

---

## Key Metrics & Insights
* **Geospatial Tracking:** Visualized sales and delivery volume across cities and regions using interactive map integration.
* **Courier & Manager Performance:** Integrated dynamic filters for Manager and Courier to monitor field coverage and regional logistics efficiency.
* **Temporal Sales Analysis:** Evaluated sales performance across different timeframes, including 3-month sales, last year's performance, and recent 1-week trends.
* **Customer Distribution:** Analyzed active buyer counts per region to identify high-density delivery zones.

---

## Tools & Technologies
* **Analytics Platform:** Power BI / Microsoft Excel
* **Geospatial Mapping:** Interactive Map Visuals (Bing Maps / TomTom)
* **Features:** Custom Measures, Slicers, Visual Filters
